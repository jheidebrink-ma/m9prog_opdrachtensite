## AI-start: van prompt naar eerste resultaat
{: .text-green-100 .fs-6 }

AI kan je helpen om sneller een begin te maken met een website. Het kan ideeën, HTML, CSS, PHP-uitleg en foutoplossingen voorstellen. Jij blijft verantwoordelijk voor het resultaat: je test de code, leest hem terug en past hem zelf aan.

## Werk in vier stappen

### 1. Bepaal je doel

Beschrijf eerst voor wie je portfolio is en wat een bezoeker moet kunnen vinden. Bijvoorbeeld: een stagebedrijf moet in één minuut kunnen zien wie je bent, welke technieken je gebruikt en welke projecten je hebt gemaakt.

### 2. Geef AI duidelijke context

Een vage prompt als `maak een mooie website` geeft een vaag resultaat. Geef rol, doel, inhoud, techniek en vormgeving mee.

```text
Je bent een WordPress-theme developer. Help mij een eerste opzet te maken
voor een persoonlijke portfolio voor een software developer die stage zoekt.
Gebruik een custom WordPress-theme met PHP-templates. Ik wil een homepagina,
over-mij-pagina, projectoverzicht, drie projectkaarten en contactsectie.
De stijl is rustig en professioneel, mobile-first, met semantische HTML.
Leg per bestand uit wat het doet. Geef geen bestanden die ik niet nodig heb.
```

### 3. Controleer het resultaat

- Plaats gegenereerde code nooit blind in je project.
- Controleer bestanden lokaal in WordPress en lees foutmeldingen.
- Vraag AI om code regel voor regel uit te leggen als je iets niet begrijpt.
- Vergelijk de output met de eisen van deze opdracht.
- Pas namen, tekst, ontwerp en code aan zodat het jouw portfolio wordt.

### 4. Bewaar bewijs

Maak twee bestanden in de hoofdmap van je repository:

- `prompt.md`: de volledige prompt en relevante AI-antwoorden.
- `ai-log.md`: wat je gebruikte, wat je hebt gecontroleerd, wat niet werkte en welke aanpassingen je zelf deed.

AI mag je sneller laten starten. Het eindproduct moet aantoonbaar van jou zijn en je moet elke belangrijke technische keuze kunnen uitleggen.
