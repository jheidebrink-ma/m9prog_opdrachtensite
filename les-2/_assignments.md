## Local development setup
{: .text-green-200 .fs-5 }

1. Clone of maak je Git-repository en voeg een goede `.gitignore` toe.
2. Start WordPress en MySQL lokaal met Docker. Bewaar geheimen alleen in `.env`; commit dit bestand niet.
3. Rond de WordPress-installatie af en controleer de voorkant en `/wp-admin`.
4. Maak in `wp-content/themes/` een map voor jouw portfolio-theme en activeer deze.
5. Leg in de README uit welke commando's nodig zijn om jouw lokale omgeving te starten.

**Resultaat:** een werkende lokale WordPress-omgeving met een actief eigen theme.
